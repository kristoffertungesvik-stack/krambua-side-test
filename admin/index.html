Koble til

Endre repo (vanlegvis ikkje nødvendig)

Slik lagar du tilgangsnøkkelen (éin gong)

  1. Logg inn på github.com og gå til Settings → Developer settings → Personal access tokens → Fine-grained tokens, eller opne denne lenka.
  2. Namn: Krambua admin. Utløp: vel lengst mogleg (til dømes 1 år).
  3. Under Repository access: vel Only select repositories og vel Krambua-meny.
  4. Under Permissions → Repository permissions: set Contents til Read and write.
  5. Trykk Generate token, kopier nøkkelen og lim han inn her. Nettlesaren hugsar han på denne eininga.

Nøkkelen gjeld berre dette eine repoet. Mistar du han, slettar du han på same stad på GitHub. Del han ikkje med andre.
